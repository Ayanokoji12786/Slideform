Output format
Structured summary recommended
One row per slide, in a single sheet. Finds "Label: Value" pairs on each slide (Business Case, Owner, Risks, and so on) and turns them into columns automatically. Best for fact-sheet-style slides, like status or demand trackers.
All native tables
One worksheet per slide. Copies every native table on the slide, positioned roughly where it sits visually. Good when you want the original tables preserved as-is rather than reshaped into one summary.
First table only
Same as All native tables, but only the first table on each slide — useful when a slide has one real data table plus a small decorative one you don't want.
Convert All checkbox above
Ignores the filter keyword and slide numbers entirely and processes every slide in the deck using Structured summary, with a fallback for slides that don't match the usual layout so nothing is silently skipped.
Column order in Export
Optionally paste your own comma-separated header row (from an existing tracker export, for example) to force Structured summary and Convert All to always output exactly those columns, in that order — filled where a slide has the data, left blank otherwise.

Automated extraction can misplace or miss content, especially in Structured summary mode. Always check the downloaded workbook and correct anything that looks wrong before using it.
